# Install the Artemis Switch NRO

Use one of these files from `dist/nro`:

1. Easy install: extract `Artemis-Switch-SD.zip` to the root of the Switch SD card.
2. Manual install: copy `Artemis-Switch.nro` to `sdmc:/switch/Artemis-Switch/Artemis-Switch.nro`.

Launch the Homebrew Menu with title redirection/full RAM mode, then select Artemis Switch. Applet mode is not supported for reliable streaming.

The ZIP contains only the ready-to-copy `switch/Artemis-Switch/Artemis-Switch.nro` layout. Apollo and Sunshine both use the normal Moonlight/GameStream pairing flow.
