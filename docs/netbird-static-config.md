# Limited static NetBird mode

Artemis can use a small, offline NetBird bundle when the Switch build includes
the WireGuard backend. This mode reuses the Switch WireGuard tunnel and does
not implement the NetBird management service, signal service, ICE, relays,
peer discovery, roaming, or automatic key rotation.

Select NetBird in Artemis Settings and browse to a JSON file with this shape:

```json
{
  "PrivateKey": "<wireguard-private-key>",
  "Address": "100.100.100.10/16",
  "ListenPort": 51820,
  "MTU": 1280,
  "Peers": [
    {
      "PublicKey": "<netbird-peer-public-key>",
      "PresharedKey": "<optional-preshared-key>",
      "AllowedIPs": ["100.100.100.20/32"],
      "Endpoint": "peer.example.net:51820",
      "PersistentKeepalive": 25
    }
  ]
}
```

The file may also be a normal WireGuard `.conf`; it is passed directly to the
same backend. The JSON file generated by a NetBird Docker enrollment is a
client bootstrap/profile file, not this static peer bundle: it does not carry
the peer map and cannot by itself create a tunnel on the Switch.

NetBird and WireGuard configuration rows support Browse and View.
View is read-only and masks private keys, preshared keys, setup/auth/API keys,
tokens, secrets, and passwords.
